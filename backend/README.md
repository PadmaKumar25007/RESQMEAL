# ResQMeal API

Node.js + Express + MongoDB + Mongoose foundation.

## Setup

1. Copy `.env.example` to `.env` and set `MONGODB_URI` and `JWT_SECRET`.
2. Run `npm install` inside `backend`.
3. Start with `npm run dev` (or `npm start`).

Authentication routes, role guards, donation/request/delivery routes, and AI/image integrations will be added next.
